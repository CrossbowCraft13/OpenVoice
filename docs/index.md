# 🎙️ OpenVoice

**A private, local-first AI assistant for Android**

OpenVoice is a fully open-source Android voice assistant that runs entirely on-device. No cloud services. No telemetry. Your voice stays on your phone.

## Why OpenVoice?

- **🔒 Private** — All processing is local. No data ever leaves your device.
- **📡 Offline** — No internet connection required for core functionality.
- **🔓 Open Source** — Apache 2.0 licensed. Fully auditable.
- **🧠 Intelligent** — Local LLM, memory, knowledge graph, autonomous planning.
- **🛠 Extensible** — Plugin SDK (coming soon).

## Quick Start

1. [Download the latest APK](https://github.com/CrossbowCraft13/openvoice/releases)
2. Install on your Android device
3. Say **"Hey OpenVoice, open Spotify"**
